Models & runtimes

Verba runs entirely on your machine. It auto-detects local runtimes at startup and assigns a model to each role.

Role assignment

Each job gets the model that fits it: the judge needs the strongest reasoning, the task generator can run on something smaller and faster.

Download guide

LM Studio / Ollama — grab the GGUF Q4_K_M build (~5.2 GB for an 8B model). Both runtimes expose an OpenAI-compatible endpoint that Verba probes automatically.

MLX (Apple Silicon) — install mlx-lm and pull mlx-community/Qwen3-8B-4bit (~4.5 GB). Same model, faster on M-series chips.

Recommended: Qwen3-8B or Qwen2.5-7B-Instruct for tutor and judge; Llama-3.2-3B is enough for task generation on modest hardware.

Prototype note. Runtime statuses and model lists here are simulated. In the real app, Verba probes localhost:1234 (LM Studio), localhost:11434 (Ollama) and the local MLX server at startup, then assigns roles automatically.
